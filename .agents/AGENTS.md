# Rules pour l'Agent Antigravity

## Règle de Commit
1. **Pré-syntaxes obligatoires** :
   - `[CREATE]` : Pour la création de nouveaux fichiers, ressources ou fonctionnalités.
   - `[UPD]` : Pour la mise à jour, la modification ou le refactoring de fichiers ou fonctionnalités existants.
   - `[DLT]` : Pour la suppression de fichiers, composants ou fonctionnalités.

2. **Format des réponses** :
   - À la fin de chaque réponse impliquant des modifications, créations ou suppressions de fichiers/code, donner systématiquement le message de commit rédigé en français à copier-coller dans Antigravity.
